# 技能

可反复使用的方法放这里。笔记是原料，技能是能换题再做的步骤。

## 什么算一项技能

- 换一个题目，步骤仍然能用。
- 写清输入、做法、做完的标准。
- 不依赖某一次的具体标的、某个人的原话，或未公开材料。

读书摘要放 `books/`。只有抽出一套自己能执行的步骤时，才在这里写一篇，并链回那份摘要。

## 怎么新增

1. 复制 [templates/skill.md](../templates/skill.md)。
2. 文件名用技能本身，例如 `如何把一本书蒸馏成要点.md`。
3. 每一步只做一件事。
4. 「例」只用虚构情景。

不要整段搬入别人的技能包或课程讲义。步骤用自己的话写。
