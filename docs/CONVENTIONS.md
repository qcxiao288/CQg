# 写作约定

## 一个主题一个文件

- 使用 Markdown（`.md`）。
- 文件名用简短中文，或 `日期-主题`，不要加空格。
- 一篇只讲一件事。写长了就拆开，并在文首互相链接。

## 文首信息（可选）

需要以后检索时，把下面四行放在文件最上方：

```yaml
---
title: 标题
tags: [标签]
updated: YYYY-MM-DD
status: draft
---
```

`status` 只用三个值：

- `draft`：草稿
- `active`：还在用
- `archived`：留档，不再更新

## 事实、传闻、推断

研究类笔记把三者分开写，不要塞进同一段。

- **事实**：你核对过。写上来源、日期、位置。
- **传闻**：听说的，尚未核实。写上从哪听到、何时听到。
- **推断**：你的判断。写上依据，以及哪里可能是错的。

对不上就写「未知」。不要把空缺补成看起来像事实的句子。

## 不写投资建议

- 不写某个标的该买、该卖或该持有。
- 不写预期收益、胜率或仓位指令。
- `trading/` 只记方法和检查项，不记成交。

## 收件箱

- 新想法先放 `inbox/`，不必写完整。
- 每周看一次：移到对应文件夹、改写成技能，或删除。
- 移出之前补上标题。涉及研究的，标清事实、传闻、推断。
