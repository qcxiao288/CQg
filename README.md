# CQg

传奇的技能。这是个人知识库，用来存放笔记和可以反复使用的方法。

公开仓库。只放整理后的通用内容，不写私人数据、具体标的，也不写收益承诺。

## 记一条笔记

1. 复制 [templates/note.md](templates/note.md)。
2. 先放进 [inbox/](inbox/README.md)。文件名用 `日期-主题.md`，例如 `2026-11-23-某主题.md`。
3. 每周整理时移到对应文件夹，或改写成 [skills/](skills/README.md) 里的一项技能。
4. 需要检索时，按 [docs/CONVENTIONS.md](docs/CONVENTIONS.md) 加上文首信息。

句子不完整也可以先收下。离开收件箱之前，补上标题；研究类内容要标明事实、传闻、推断。

## 加一项技能

1. 复制 [templates/skill.md](templates/skill.md) 到 `skills/`。
2. 一项技能一个文件，写清：做什么、何时用、步骤、怎样算做完。
3. 格式示例（空白，待自己填写）：[skills/如何把一本书蒸馏成要点.md](skills/如何把一本书蒸馏成要点.md)。

技能要能换一个题目再做一遍。只对一次阅读、一条消息有用的内容，留在笔记里。
