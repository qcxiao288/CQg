# 研究

题材、市场结构和公开资料的整理。一个问题一个文件。

## 三段分开

| 标记 | 含义 | 写上 |
| --- | --- | --- |
| 事实 | 有出处，且你核对过 | 来源、日期、位置 |
| 传闻 | 听说的，还没核实 | 从哪听到、何时 |
| 推断 | 你的判断 | 依据、哪里可能错 |

对不上就标「未知」。

## 边界

- 可以写核对清单，例如这条消息还缺哪几项出处。
- 不写具体标的的买卖结论，不写目标收益。
- 私人聊天、未公开数据、他人的系统规则不要贴进来。本仓库是公开的。

从 [templates/note.md](../templates/note.md) 复制。每周整理时，过期传闻改为 `archived` 或删除。写作约定见 [docs/CONVENTIONS.md](../docs/CONVENTIONS.md)。
