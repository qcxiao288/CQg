# 收件箱

临时放下还没归类的想法。句子不完整也可以。

## 怎么用

1. 新笔记放在这里。可从 [templates/note.md](../templates/note.md) 复制。
2. 每周看一遍。
3. 能归类的，移到 `books/`、`research/`、`trading/`、`content/`，或改写成 `skills/` 里的技能。
4. 用不上的删除。

移出之前给文件一个清楚的标题。研究类内容按 [docs/CONVENTIONS.md](../docs/CONVENTIONS.md) 标明事实、传闻、推断。

格式示例（虚构）：[2026-11-23-虚构示例.md](2026-11-23-虚构示例.md)
