# 交易方法

只记方法、流程和复盘时要问的问题。

## 放什么

- 动手前要检查的问题类型（写问题，不写具体答案）。
- 事后复盘要回答的问题。
- 对一套方法的理解。引自公开资料的标明出处；自己的判断标成推断。

能换情境重复使用的步骤，抽到 `skills/`，这里留链接。

## 不放什么

- 成交、持仓、账户、券商或个人信息。
- 具体标的、价位、仓位、收益目标。
- 对任何标的的买卖判断。

题材和消息放 [research/](../research/README.md)，并分开写事实、传闻、推断。新笔记可从 [templates/note.md](../templates/note.md) 复制。
